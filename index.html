🚁 病院前救護・ドクターヘリ特有の注意点

⏱ 10分ルール 現場滞在は原則10分以内。エコーは必要最小限のビュー（2-リージョン法）を迅速に。
🔊 聴診不可 エンジン騒音で聴診困難。肺・心エコーが聴診の代替となる。呼吸音はエコーで視覚的評価。
📳 振動アーチファクト 機体振動により偽像が生じうる。Lung slidingの判断に注意。Mモードを活用。
🏥 搬送先選定 POCUSで心タンポナーデ・大量血胸・腹腔内出血を確認→ 専門センター（外傷・心臓外科）へ直接搬送。
🩸 REBOA適応 骨盤骨折+腹腔内出血でFASTが陽性→ REBOA留置を検討。大動脈エコーで確認。
📡 RT-MUS 現場画像をリアルタイムで病院専門医に送信。遠隔診断支援（Remote Tele Medical Ultrasound）。
🔋 機材 バッテリー駆動のポータブル超音波装置使用。プリセット活用（D4.50）。深さ・ゲイン調整（D4.51-D4.54）。
🎯 プロトコル優先 eFAST（外傷）、RUSH exam（ショック）、BLUEプロトコル（呼吸困難）を状況に応じて選択。

🌊 災害医療特有の知識・エコーの役割

📊 CAVEATプロトコル eFASTにIVC評価・骨折・DVT検索を加えた災害時専用プロトコル。多数傷病者(MCI)トリアージに。
🏚 超急性期 心タンポナーデ、大量血胸、腹腔内出血を数分で同定→ 即時救命処置。停電でもバッテリー駆動。
🪑 DVTスクリーニング 避難所・車中泊→ エコノミークラス症候群が急増。膝窩静脈圧迫法による集団スクリーニングが重要。
💔 たこつぼ心筋症 災害ストレスで増加。FoCUSで心尖部壁運動消失・基部収縮良好のパターンを確認。
💪 クラッシュ症候群 長時間挟圧後の筋細胞崩壊。腎血流RI値測定・IVC管理で透析適応・補液量を判断。
🌬 肺水腫・感染 避難所生活→ 心不全増悪・肺炎。Bライン（肺水腫）・肺実質化（肺炎）を鑑別。
☢ CBRNE対応 防護服下での身体診察補完にエコー。聴診・触診制限下でも心肺評価が可能。
🔋 インフラ途絶環境 X線・CT使用不可。エコーが唯一の画像診断ツール。プリセット設定の事前確認が必須。

💧 IVC判読まとめ

↓
虚脱（<10mm）：循環血液量減少 → 輸液適応
↔
正常（10-20mm、呼吸変動あり）：正常補液状態
↑
拡大（>21mm、変動消失）：右心負荷 / 閉塞性ショック
ℹ ドクターヘリでは呼吸変動が振動で見えにくい場合あり。絶対径も参考に。

📚 疾患知識リファレンス

🚁 ヘリ特有・見逃し禁止疾患

  • 心タンポナーデ：ベック三徴（低血圧・頸静脈怒張・心音減弱）→ セクタで心嚢液確認→ 心膜穿刺
  • 緊張性気胸：Lung sliding消失→ 即時脱気（第2肋間鎖骨中線）
  • 大量血胸：外傷 + 呼吸音減弱 → eFAST胸腔液体確認
  • 腹腔内出血：FAST陽性 + ショック → 専門センター直搬
  • Stanford A解離：左右血圧差 + 胸背部痛 → 長軸でフラップ確認
  • PE + 右室拡大：ROSC後 + DVT → Dシェイプ確認→ ヘパリン

🌊 災害特有疾患

  • クラッシュ症候群：長時間挟圧 → ミオグロビン尿（赤褐色）→ 腎保護輸液（生食1L/h）
  • たこつぼ心筋症：心尖部無収縮 + 基部収縮良好 + ストレス歴
  • エコノミークラス症候群：避難所生活 → DVT → PE。予防は足首運動。
  • 誤嚥性肺炎：高齢者 + 避難所 → 右下葉実質化 → セフトリアキソン
  • 低体温症：体温<32°C → J波(Osborn波)→ 能動的加温、VF注意
  • 溺水：両側Bライン + 実質化 → ALI/ARDS → 保護的換気

📊 ショック分類と初期対応

  • 循環血液量減少性：輸液（細胞外液500-1000mL）→ 反応性確認
  • 心原性：利尿薬、強心薬。輸液は禁忌。専門科コンサル。
  • 閉塞性（気胸）：即時脱気→ 胸腔ドレナージ。輸液は不要。
  • 閉塞性（タンポ）：心膜穿刺→ 輸液禁忌。
  • 閉塞性（PE）：酸素化、ヘパリン（静注）。輸液慎重に。
  • 分布異常性（敗血症）：輸液 + 抗菌薬（1時間以内）+ 昇圧薬
